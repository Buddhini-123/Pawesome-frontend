Loyalty Card - Functional Requirements
1. User Registration & Account Management
Allow users to register for the loyalty program.
User profile (pet details, subscriptions) linked to loyalty card – there should be a common page, where user can see his or her profile. It should include past orders, status of current orders, subscriptions and loyalty card.
Option to opt in/out of promotional emails or SMS
View loyalty card details in user profile
Gamification (badges – when points are high you give badges)
 
2. Points Management
Award loyalty points automatically upon successful order/payment
Define points rules (1 point per 10 LKR spent)
Points issued should have configurable expiry (valid for 12 months)- minimum 100 points will remain. The rest will be donated to pet adoption and welfare centers. 
View points history (earned, redeemed, expired)
Real-time points balance update after each transaction
3. Redemption & Checkout Integration
Option to redeem points during checkout
Customizable rules for redemption (e.g., 10 points = 1 LKR )
Allow partial or full redemption of available points
Ensure redeemed value is reflected in order invoice and payment
4. Exclusive Discounts for Loyalty Members
Apply additional % discount in deals (like what keels does)
Display loyalty-exclusive deals/offers on deals page
5. Admin Portal / Backend Features
Add/edit/delete loyalty rules (e.g., earning & redemption logic)
Set promotional bonus points (e.g., double points weekends)
Generate reports (e.g., most loyal customers, points redeemed this month)
Manage user accounts and loyalty statuses
Notifications system (e.g., send alerts for point expiry)
 
🎯  Additional points we can give
Referral bonus (points for referring new users)
Birthday or anniversary bonus points
